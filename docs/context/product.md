# Product

**Vox** — open-source, local-first voice agent for desktop (macOS + Windows). Press a key, speak an intent, and the agent executes it: system actions, MCP connector calls (Filesystem, GitHub), or text insertion at the cursor. Side effects always pause for explicit confirmation. Responses render as text in a session transcript.

Prototype scope and success criteria: see [PRD-v1.1-prototype.md](../../PRD-v1.1-prototype.md) §1.3–§4.

Working codename: **Vox** (repo). Product-name shortlist (Parla, Cue) pending trademark screening (PRD §2).
