The problem

Assistants that talk. Tools that wait.

Cloud assistants ship your voice to someone else’s servers and hand back a paragraph. OS assistants set timers. The actual work — moving files, filing the issue, checking the calendar — still means finding the window, clicking through menus, and retyping context you already have. Vox closes that gap: an agent that lives on your desktop, hears you locally, and does the thing.

No context-switching

The hotkey works from any app. Dictate into your editor, file a GitHub issue, or check tomorrow’s calendar without ever leaving the window you’re in.

No audio upload

Speech is transcribed on your machine by whisper.cpp and processed in memory. There is no server to trust, because there is no server.

No blind automation

Every side effect is shown as the exact tool and parameters before it runs. One glance, one click — nothing happens behind your back.

How it works

From voice to action in four beats.

01

Hold the hotkey

⌥ Space — or any binding you record — from any app, focused or not. A small pill appears; Vox is listening only while you hold it.

02

Speak

whisper.cpp transcribes on-device in about a second, with built-in voice-activity detection. Audio stays in memory and is never written to disk.

03

The agent plans

A LangGraph agent picks the right tool for the job — your filesystem, GitHub, Gmail, Calendar, a system action, or any MCP server you’ve connected.

04

You approve

Reads run instantly. Anything that changes state pauses and shows you the exact call. Approve it, or deny it and the action is cleanly cancelled.

Features

Small surface. Serious machinery.

A Rust core, an on-device speech pipeline, and a tool-calling agent — wired together so the whole thing feels like one keystroke.

On-device speech-to-text

whisper.cpp with Silero voice-activity detection turns speech to text in about a second — offline, private, and never persisted.

Confirm before acting

Default-deny classification: only an explicit read-only allowlist skips the gate. Everything else shows the exact tool and parameters and waits for your yes.

Connect your whole stack

One-click Google Workspace connectors with built-in OAuth, GitHub, your filesystem — plus a custom entry for any server that speaks MCP. Toggle each on or off.

Cloud or fully local reasoning

Groq for fast cloud inference by default, or Ollama to keep reasoning on your own hardware. One toggle in settings — the rest of the pipeline is identical.

Ambient context

Vox knows which app you’re in front of, so “open a new tab in this app” just resolves — no repeating yourself, no explaining where you are.

Secrets stay in the keychain

API keys and OAuth tokens live in the OS keychain — never in config files or logs. Local channels are token-authenticated; the UI runs under a strict CSP.

Private by default

Your voice is not a product.

Most voice assistants are microphones for someone else’s cloud. Vox is architected the other way around: privacy is the default state, and every exception is one you explicitly choose.

  • Audio is transcribed on-device and processed in memory — never uploaded, never written to disk, never retained.
  • Transcripts vanish with the window unless you opt in to local history — and switching it off erases what was saved.
  • Secrets never touch config files. Keys and tokens live in the macOS Keychain or Windows Credential Manager, full stop.
  • Local mode goes all the way. With Ollama, speech, reasoning, and action all run on your hardware — no network required.
